1. Overview

Better Excalidraw Workspace adds local workspace, multi-canvas switching, autosave, and geometry tools to excalidraw.com.

Local-first. The extension does not send personal data or drawing content to a developer-operated server.

2. Information processed locally

  • Folder and file names inside the selected workspace.
  • .excalidraw elements, app state, and embedded images.
  • Canvas data stored by excalidraw.com when needed to save.
  • The directory handle in extension-local IndexedDB.
  • Preferences in chrome.storage.local.

A third-party sync service may separately process files if you selected a synced folder.

3. Chrome permissions

  • sidePanel opens the workspace.
  • storage saves local preferences.
  • https://excalidraw.com/* enables canvas loading, capture, saving, and tools on the official site.
  • Folder access begins only after you use Chrome's directory picker.

The Manifest V3 package does not download or execute remote code.

4. Third parties

Chrome provides the extension platform and File System Access controls. Excalidraw may process website activity under its own policy. The extension does not use analytics, advertising, tracking, telemetry, accounts, or a developer backend.

5. Retention and choices

Files remain until you edit or delete them. The directory handle and preferences remain in browser-local storage until cleared, reset, or removed with the extension, subject to browser and operating-system behavior.

1. 概述

Better Excalidraw Workspace 为 excalidraw.com 增加本地工作区、多画布切换、自动保存和几何图形工具。

本地优先。扩展不会将个人数据或绘图内容发送至开发者运营的服务器。

2. 在本地处理的信息

  • 所选工作区中的目录名与文件名。
  • .excalidraw 元素、应用状态和内嵌图片。
  • 保存时所需的 excalidraw.com 浏览器本地画布数据。
  • 扩展本地 IndexedDB 中的目录句柄。
  • chrome.storage.local 中的偏好。

如果选择了同步目录，第三方同步服务可能依据自身条款处理文件。

3. Chrome 权限

  • sidePanel 用于打开工作区。
  • storage 用于保存本地偏好。
  • https://excalidraw.com/* 用于在官方网站加载、读取、保存画布并提供工具。
  • 仅在您使用 Chrome 目录选择器后取得目录权限。

Manifest V3 扩展包不会下载或执行远程代码。

4. 第三方

Chrome 提供扩展平台和文件系统访问控制；Excalidraw 可能依据自身政策处理网站活动。扩展不使用分析、广告、追踪、遥测、账户或开发者后端。

5. 保留与选择

文件保留至您自行修改或删除。目录句柄与偏好保存在浏览器本地，直到被清理、重置或随扩展移除；实际行为可能受浏览器与操作系统影响。
