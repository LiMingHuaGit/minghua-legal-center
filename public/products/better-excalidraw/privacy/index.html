1. Overview

Better Excalidraw Workspace enhances the official excalidraw.com website with a local workspace, multi-canvas switching, autosave, and additional geometry tools.

Local-first by design. The extension does not collect, sell, rent, or transmit personal data or drawing content to a developer-operated server.

2. Information processed locally

When you choose a workspace folder, the extension may read and write the following information on your computer to provide the features you request:

  • Folder and file names inside the workspace you select.
  • .excalidraw canvas content, including elements, app state, and embedded image data.
  • Excalidraw canvas data already stored by excalidraw.com in browser local storage or IndexedDB, when needed to save the active canvas.
  • The selected directory handle, stored in the extension's browser-local IndexedDB so the workspace can be reconnected.
  • Extension preferences, such as the autosave interval, stored in chrome.storage.local.

The extension accesses only a folder you explicitly select through Chrome's directory picker. If that folder is managed by a third-party sync or backup service, that service may process files under its own terms; the extension does not initiate or control that service.

3. Chrome permissions

sidePanelOpens the workspace interface in Chrome's side panel.
storageSaves extension preferences locally in Chrome.
https://excalidraw.com/*Runs the extension only on the official Excalidraw website to load, capture, save, and enhance canvases.
Directory accessChrome asks you to choose and authorize a workspace folder. The extension cannot silently select an arbitrary folder.

The extension is packaged as a Manifest V3 extension and does not download or execute remote code.

4. Collection, sharing, and third parties

The extension does not use analytics, advertising, tracking, telemetry, user accounts, or a developer backend. It does not sell or share user data for advertising, profiling, credit, or unrelated purposes.

Google Chrome provides the extension platform, local extension storage, side panel, and File System Access controls. The official Excalidraw website may separately process information under its own privacy terms. This policy covers only the Better Excalidraw Workspace extension.

If you voluntarily email the publisher for support or a privacy request, the email address, message, and attachments you provide are processed by the applicable email service only as needed to respond, keep an appropriate request record, protect the service, or comply with law.

5. Retention, security, and your choices

  • Workspace files remain in the folder you selected until you edit or delete them.
  • The directory handle and extension preferences remain in browser-local storage until cleared by Chrome, reset by you, or removed when the extension is uninstalled, subject to browser and operating-system behavior.
  • You can revoke directory access through Chrome's site or permission controls and can uninstall the extension at any time.

The extension relies on Chrome's permission model and keeps processing local where practical. No storage method is completely secure, so you should protect access to your device and workspace files and maintain backups appropriate for your needs.

The extension is a productivity tool and is not directed to children below the minimum digital-consent age in their region.

6. Changes and contact

This policy may be updated before a release if the extension's features, permissions, external services, or data practices change. The effective date above identifies the current version.

1. 概述

Better Excalidraw Workspace 为官方 excalidraw.com 网站提供本地工作区、多画布切换、自动保存和扩展几何图形功能。

本地优先。扩展不会收集、出售、出租个人数据，也不会将个人数据或绘图内容传输至开发者运营的服务器。

2. 在本地处理的信息

当您选择工作区目录后，为提供您主动使用的功能，扩展可能在您的电脑上读取和写入：

  • 您所选工作区内的目录名和文件名。
  • .excalidraw 画布内容，包括元素、应用状态及内嵌图片数据。
  • 在保存当前画布时，读取 excalidraw.com 已保存在浏览器 localStorage 或 IndexedDB 中的画布数据。
  • 您选择的目录句柄；该句柄保存在扩展的浏览器本地 IndexedDB 中，以便重新连接工作区。
  • 自动保存间隔等扩展偏好；这些设置保存在 chrome.storage.local 中。

扩展仅访问您通过 Chrome 目录选择器明确选择的目录。如果该目录由第三方同步或备份服务管理，该服务可能依据自身条款处理文件；扩展不会主动启动或控制该服务。

扩展不使用分析、广告、追踪、遥测、用户账户或开发者后端，也不会为广告、画像、征信或无关目的出售或共享用户数据。

Google Chrome 提供扩展平台、本地扩展存储、侧边栏和文件系统访问控制；官方 Excalidraw 网站可能依据其自身隐私条款独立处理信息。本政策仅适用于 Better Excalidraw Workspace 扩展。

如果您主动向发布者发送支持或隐私请求邮件，您提供的邮箱地址、邮件正文和附件会由相应邮箱服务处理，并仅在回复请求、保留适当记录、保护服务或履行法律义务所需期间使用。

5. 保留、安全与您的选择

  • 工作区文件保留在您选择的目录中，直到您自行修改或删除。
  • 目录句柄和扩展偏好保留在浏览器本地存储中，直到 Chrome 清理、您主动重置或卸载扩展；实际行为可能受浏览器和操作系统机制影响。
  • 您可以通过 Chrome 的网站或权限设置撤销目录访问，也可以随时卸载扩展。

扩展依赖 Chrome 权限模型，并在可行范围内保持本地处理。任何存储方式都无法保证绝对安全，请妥善保护设备和工作区文件，并根据需要自行备份。

本扩展属于生产力工具，不面向低于所在地区最低数字同意年龄的儿童。
